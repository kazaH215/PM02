
## 🎯 Функциональные возможности

### По ролям:

#### 👤 Клиент
- Создание заявок с указанием описания, приоритета и срока
- Просмотр своих заявок
- Отслеживание статуса выполнения
- Добавление комментариев
- Просмотр истории оказанных услуг

#### 👔 Менеджер
- Просмотр всех заявок
- Утверждение заявок (смена статуса с «Новая» на «В работе»)
- Назначение исполнителей (программистов)
- Изменение приоритета задач
- Формирование отчётности

#### 💻 Программист
- Просмотр назначенных заявок
- Изменение статуса по мере выполнения
- Добавление комментариев о ходе работ
- Автоматическая отправка письма клиенту при завершении

#### 🔧 Администратор
- Управление учётными записями пользователей
- Активация и деактивация сотрудников
- Просмотр всех данных системы
- Назначение ролей
- Управление справочником услуг и статусов

## 🐛 Часто встречающиеся проблемы

| Проблема | Решение |
| :--- | :--- |
| Ошибка подключения к БД | Проверьте строку подключения в файле `appsettings.json` |
| API не отвечает | Убедитесь, что серверная часть запущена и порт указан верно |
| Не удаётся войти | Проверьте логин и пароль. Используйте тестовые данные: `admin / 1` |
| Приложение не запускается | Убедитесь, что установлен .NET 8 SDK |
