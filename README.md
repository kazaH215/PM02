# 📋 ServiceDesk — Система учёта заявок на сопровождение 1С

## 📌 О проекте

ServiceDesk — это корпоративная система для управления заявками на сопровождение и модификацию программных продуктов 1С, разработанная для ООО «МастерСофт-Сервис».

Система позволяет клиентам подавать заявки на доработку или консультацию, менеджерам — утверждать и назначать программистов, разработчикам — отслеживать и выполнять задачи, а администраторам — управлять пользователями и справочниками.

## 🏗️ Архитектура

Проект построен по двухзвенной архитектуре:

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| Сервер | ASP.NET Core 8 Web API | REST API, бизнес-логика, работа с БД |
| Клиент | WPF (.NET 8) | Настольное приложение с графическим интерфейсом |
| База данных | Microsoft SQL Server | Хранение данных |

## ⚙️ Технологический стек

### Серверная часть (ServiceDeskAPI)
- ASP.NET Core 8 — веб-фреймворк
- Entity Framework Core — ORM для работы с БД
- SQL Server — база данных
- Swagger/OpenAPI — документация API
- CORS — кросс-доменные запросы
- SMTP Client — отправка уведомлений на почту
- HttpClient — интеграция с 1С:Бухгалтерия

### Клиентская часть (ServiceDeskClient)
- .NET 8 — платформа
- WPF — графический интерфейс
- MVVM — архитектурный паттерн
- Newtonsoft.Json — сериализация/десериализация JSON
- HttpClient — HTTP-запросы

### Тестирование
- NUnit — модульное тестирование
- Moq — создание мок-объектов
- Postman — тестирование API
- WebApplicationFactory — интеграционное тестирование

## 🚀 Быстрый старт

### Шаг 1: Клонирование репозитория
Скачайте или склонируйте репозиторий с исходным кодом.

### Шаг 2: Настройка базы данных
1. Откройте SQL Server Management Studio (SSMS).
2. Выполните скрипт создания базы данных (`CreateDatabase.sql`).
3. Заполните тестовыми данными (`SeedData.sql`).

### Шаг 3: Запуск серверной части
1. Откройте решение `ServiceDesk.sln` в Visual Studio.
2. Запустите проект `ServiceDeskAPI`.
3. API будет доступен по адресу: `https://localhost:7047/swagger`.

### Шаг 4: Настройка клиента
Перед запуском клиента убедитесь, что в файле настроек (`appsettings.json`) указан правильный адрес API.

### Шаг 5: Запуск клиента
1. В Visual Studio запустите проект `ServiceDeskClient`.
2. Откроется окно входа в систему.

## 🎯 Функциональные возможности

### По ролям:

#### 👤 Клиент
- Создание заявок с указанием описания, приоритета и срока
- Просмотр своих заявок
- Отслеживание статуса выполнения
- Добавление комментариев
- Просмотр истории оказанных услуг

#### 👔 Менеджер
- Просмотр всех заявок
- Утверждение заявок (смена статуса с «Новая» на «В работе»)
- Назначение исполнителей (программистов)
- Изменение приоритета задач
- Формирование отчётности

#### 💻 Программист
- Просмотр назначенных заявок
- Изменение статуса по мере выполнения
- Добавление комментариев о ходе работ
- Автоматическая отправка письма клиенту при завершении

#### 🔧 Администратор
- Управление учётными записями пользователей
- Активация и деактивация сотрудников
- Просмотр всех данных системы
- Назначение ролей
- Управление справочником услуг и статусов

## 🐛 Часто встречающиеся проблемы

| Проблема | Решение |
| :--- | :--- |
| Ошибка подключения к БД | Проверьте строку подключения в файле `appsettings.json` |
| API не отвечает | Убедитесь, что серверная часть запущена и порт указан верно |
| Не удаётся войти | Проверьте логин и пароль. Используйте тестовые данные: `admin / 1` |
| Приложение не запускается | Убедитесь, что установлен .NET 8 SDK |
